# Bharath MM — Portfolio Website

A terminal-aesthetic developer portfolio built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/BHARATHMM562/Portfolio)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Environment Variables

No environment variables are required for this project. All content is sourced from `data/portfolio.ts`.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Testing**: Vitest + fast-check (property-based tests)

## Testing

```bash
npm test
```

Runs unit and property-based tests across all components.

## Deployment

Deploy to Vercel with one click using the button above. No additional configuration required.
